## 🛡️ **Safety Precautions:**

### Before Enabling:
- [ ] Close all other tabs running the scanner
- [ ] Save any important work (browser might freeze)
- [ ] Be ready to switch to MEDIUM if issues occur
- [ ] Note your current IP (in case you need to track ban)
- [ ] Close unnecessary browser tabs/programs

### While Running:
- [ ] Watch for 429 errors in console (F12)
- [ ] Monitor API Latency - spike = trouble
- [ ] Check scan speed - drop = getting throttled
- [ ] Set timer for 2-3 minutes maximum
- [ ] Be ready to stop immediately

### If You Get Banned:
1. **Stop scanning immediately**
2. **Switch to SLOW mode** for future
3. **Wait 30-60 minutes** before trying again
4. **Consider using VPN** to change IP
5. **Don't retry NO LIMIT** for at least 24 hours
